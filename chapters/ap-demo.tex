\chapter{Demonstration Video}
\label{append:demo}
\vspace*{2em}

A video demonstration of the deployed system accompanies this report. It is
6~minutes 54~seconds long and is available at:

\begin{center}
  \url{https://youtu.be/W2av8mtkLbQ}
\end{center}

The video was recorded on the deployed system in its hybrid configuration
(\autoref{impl:subsec:configs}), using demonstration student and instructor
accounts; no student data appears in it. It follows the four use cases of
\autoref{append:architecture}, so each segment can be read alongside the
matching figure. \autoref{append:tab:demo} lists the segments in order.

Two points should be kept in mind when watching. First, the compression stage
of \autoref{impl:sec:compression} is off in the recording, as it is by
default in the deployment, so the answers shown use uncompressed retrieval.
Second, chat turns shown in the video are not stored on the server
(\autoref{concl:sec:limitations}); the instructor analytics are computed from
quiz and assignment results only.
